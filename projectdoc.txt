Create a real-world production-ready frontend admin panel for a Property & Construction platform called UrbanKart.

This should NOT be a demo design.
This should work like a real application workflow.

Use:
- React.js
- TypeScript
- Material UI
- Redux Toolkit
- React Router
- Static mock data for now

Important:
Use static data only for now, but structure everything exactly like API response data.
Later we will integrate backend APIs, so UI should not need major changes.

==================================================

When app opens, first show Login Page.

1. Super Admin
2. Admin
3. Support Team
4. Finance Team
5. Legal Team

Do not show all features to every user.
